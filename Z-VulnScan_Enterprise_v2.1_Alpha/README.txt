[Z-VulnScan Enterprise v2.1 Alpha - 사용자 가이드]

1. 개요
   본 프로그램은 시스템의 보안 취약점을 자동으로 진단하고, 
   KISA 주요 정보통신 기반 시설 가이드라인에 따른 리포트를 생성하는 도구입니다.

2. 실행 방법
   (1) 'Z-VulnScan_Enterprise_v2.1_Alpha.exe'를 마우스 우클릭합니다.
   (2) 반드시 [관리자 권한으로 실행]을 선택하십시오. (네트워크 스캔 권한 필요)
   (3) Target IP를 입력하고 [Audit] 버튼을 클릭하면 진단이 시작됩니다.
   (4) 진단 완료 후 [Excel Report] 또는 [PDF Report] 버튼으로 결과를 확인하세요.

3. 주요 기능
   - 포트 스캔 및 서비스 취약점 분석 (CVE 기반)
   - 서버 내부 설정 진단 (SSH/WinRM)
   - 보안 점수 산정 및 조치 방안(Remediation) 제공

4. 주의 사항 (Disclaimer)
   - 본 도구는 허가된 자산에 대해서만 사용해야 합니다.
   - 타인의 시스템을 무단으로 스캔할 경우 정보통신망법에 의거 처벌받을 수 있습니다.
   - Alpha 버전이므로 예상치 못한 오류가 발생할 수 있습니다. 
     오류 발생 시 생성된 'scan.log' 파일을 개발자에게 전달해 주십시오.
