[Z-VulnScan Professional Edition - Release Notes]

■ 버전: Professional Edition_V2.1.0
■ 배포일: 2025-12-31

[1] 보안성 강화 (Security Hardening)
    - 자격증명 암호화 저장소(Secure Storage) 탑재로 계정 탈취 위험 원천 차단
    - 메모리 덤프 공격 방어를 위한 Zero-Trust 메모리 관리 로직 적용
    - 대규모 포트 스캔 시 네트워크 과부하 방지를 위한 2단계 안전장치(Safety Guard) 적용

[2] 진단 엔진 고도화 (Core Engine Update)
    - KISA 주요정보통신기반시설 기술적 취약점 분석 기준 최신화
      * Windows Server 진단 항목 확장 (80개 항목)
      * Linux Server 진단 항목 확장 (70개 항목)
    - CVE(Common Vulnerabilities and Exposures) 매칭 정확도 개선

[3] 사용자 경험 개선 (UX Improvements)
    - [New] 컨텍스트 메뉴 지원: 자산 목록 우클릭을 통한 원격 접속(RDP/SSH) 및 유틸리티 지원
    - [New] 리포트 고도화: 단순 결과 나열을 넘어, 취약점별 '상세 조치 방안(Remediation)' 제공
    - [New] 다크 모드(Dark Mode) UI 최적화 및 고해상도(HiDPI) 지원

[알려진 문제 (Known Issues)]
    - 일부 레거시 OS(Windows 7 이하)에서 UI 폰트 렌더링이 매끄럽지 않을 수 있습니다.
    - 네트워크 지연(Latency)이 심한 환경에서 진단 시간이 예상보다 길어질 수 있습니다.
