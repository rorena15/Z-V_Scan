[Z-VulnScan Professional Edition - Release Notes]

■ 버전: Professional Edition_v3.0.0
■ 배포일: 2026-01-03

[1] 핵심 신규 기능 (Major New Features)
    - [New] 네트워크 토폴로지 맵(Topology Map) 탑재
      * PyVis 엔진 기반의 인터랙티브 자산 관계 시각화
      * 인터넷 연결 없이 동작하는 독립형(Stand-alone) 오프라인 HTML 맵 생성
    - [New] 내장형 DB 매니저(Embedded DB Manager)
      * 별도 도구 없이 프로그램 내에서 스캔 이력 조회/수정/삭제 가능
      * 자산별 사용자 메모(Tagging) 작성 및 영구 저장 지원

[2] 보안 및 성능 최적화 (Security & Performance)
    - 하이브리드 난독화(Hybrid Obfuscation) 시스템 적용
      * 핵심 엔진(Core/Utils)을 C언어 레벨(.pyd)로 컴파일하여 실행 속도 향상
      * PyArmor 최신 기술 적용으로 소스 코드 변조 및 리버스 엔지니어링 원천 차단
    - 대용량 자산 데이터 처리를 위한 SQLite DB 구조 최적화

[3] UI/UX 전면 개편 (UI/UX Overhaul)
    - [New] Pro Deep Dark 테마: 장시간 분석 업무에 최적화된 고대비 디자인 적용
    - [New] 통합 대시보드(Unified View): 탭 전환 없이 설정, 인증, 포트 구성을 한눈에 제어
    - 사용자 편의성 강화: 상단 스마트 툴바(Toolbar) 도입 및 통계 현황판(Status Board) 배치
    - 피드백 개선: 입력창, 다이얼로그, 알림창까지 통일된 다크 테마 적용

[알려진 문제 (Known Issues)]
    - 토폴로지 맵 생성 시 자산 노드가 매우 많을 경우(수천 개 이상) 웹 뷰 렌더링에 다소 시간이 소요될 수 있습니다.
    - 초기 실행 시 보안 엔진 무결성 검증으로 인해 이전 버전 대비 구동 시간이 소폭 증가할 수 있습니다.
